# 📊 Character Overreach — Power Rating Reference

*Suggested power ratings for **expendable** abilities — the only ones [[start-here/character-options/Character Overreach|Character Overreach]] can force. Passive/always-on features are excluded (nothing to force). Full working copy: see the companion spreadsheet.*

> [!info] How to read this
> **Rating** feeds the DC: `DC = 20 + rating`. **Stat** is what you roll (always with proficiency); **Skill** is the Arcana/Religion/Nature flavor for narration. On a failure: `rating × level` damage + `ceil(rating ÷ 3)` exhaustion. Command form: `/overreach ability <rating> <stat> <feature>`.

## Rating rubric

| Rating | Anchor |
|:---:|:---|
| 1 | Minor, frequent — Bardic Inspiration, one Ki/Sorcery point, a 1st-level innate spell. |
| 2 | Solid per-rest minor — Second Wind, Breath Weapon, Stone's Endurance, Fey/Shadow-Touched. |
| 3 | Strong per-rest — Rage, Channel Divinity, Lay on Hands, Indomitable, Stunning Strike, Lucky. |
| 4 | Big swing / extra action — Action Surge, Wild Shape, Arcane Recovery, Stroke of Luck. |
| 5 | Major — Portent, Empty Body, Quivering Palm. |
| 6–9 | Top tier — Mystic Arcanum 6th→9th; Divine Intervention. |

Warlock **Pact Magic** isn't auto-validated by the extension's spell branch — use the ability branch for pact casters.
